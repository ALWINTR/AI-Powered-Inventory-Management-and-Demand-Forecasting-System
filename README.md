# 🤖 AI Inventory Management System

An AI-powered Inventory Management System built with **Flask**, **Python**, and **XGBoost** to help businesses efficiently manage inventory, forecast sales, detect dead stock, and generate intelligent purchase recommendations.

---

## 🚀 Features

- 📊 Interactive Dashboard
- 🤖 AI Sales Prediction (XGBoost)
- 📦 Purchase Recommendation
- ⚠️ Stock-Out Prediction
- 📉 Dead Stock Detection
- 📈 Inventory Analytics
- 📁 Excel Import & Export
- 🔐 Secure Login
- 📊 Charts & Reports
- 📱 Responsive Web Interface

## ⚙️ Installation

### Clone the repository

```bash
git clone git@github.com:ALWINTR/AI_Inventory_Management_System.git
```

### Go to the project folder

```bash
cd AI_Inventory_Management_System
```

### Create a virtual environment

```bash
python3 -m venv venv
```

### Activate the virtual environment

Linux/macOS

```bash
source venv/bin/activate
```

Windows

```cmd
venv\Scripts\activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
